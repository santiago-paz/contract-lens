Flujo: Crear Organizacion

flowchart TD
    A[Usuario se registra] --> B[Entra a /setup-organization]
    B --> C[Ingresa nombre de org]
    C --> D[createOrganization action]
    D --> E[Genera slug unico]
    E --> F[Crea Organization en DB]
    F --> G[Crea Membership con rol owner]
    G --> H[Re-genera JWT con orgId + role]
    H --> I[Redirect a /dashboard]

Flujo: Invitar Usuarios

flowchart TD
    A[Owner/Admin crea Invitation] --> B[email + role + token + expiry]
    B --> C[Se envia link con token]
    C --> D[Invitado hace click]
    D --> E{Tiene cuenta?}
    E -->|Si| F[acceptInvitation - token]
    E -->|No| G[Registro primero]
    G --> F
    F --> H{Token valido y no expirado?}
    H -->|Si| I[Crea Membership con rol asignado]
    H -->|No| J[Error: token invalido/expirado]
    I --> K[Re-genera JWT con nueva org]
    K --> L[Redirect a /dashboard]
